# 米家设备控制台

基于 Flask + FastAPI 构建的米家设备本地控制台，提供现代化 Web 界面控制小米智能家居设备。

## 文档

详细技术文档请参阅 [技术手册.md](技术手册.md)。

## 主要特性

- 小米账号登录（账号密码 + 二维码扫码两种方式）
- 基于 miot-spec 的设备控制页面（动态生成开关/滑块/下拉框）
- SQLite 持久化（操作日志、连接日志、系统设置）
- JWT 鉴权 + 登录失败锁定 + 15分钟空闲自动登出
- 系统设置（日间/夜间模式、透明度、背景图片、卡片分页）
- Tailwind CSS 现代化 UI，三栏布局
